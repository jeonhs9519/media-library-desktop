## 릴리즈 개요

- 버전: v0.2.1
- 비교 기준: v0.2.0
- `과거 데이터 불러오기`가 원본 프로필을 무시하고 현재 프로필에 데이터를 등록하던 문제를 수정했습니다.

## 과거 데이터 가져오기 수정

- 원본 사용자 프로필을 생성하고 항목·태그·리뷰·플레이리스트·설정을 해당 프로필에 복원합니다. 같은 이름의 프로필이 있으면 연결하며 기존 중복 항목·설정은 유지합니다.
- 선택한 플레이리스트와 최근 사용 프로필 ID를 새 DB의 ID로 치환합니다. GUEST 데이터는 GUEST에, 프로필 정보가 없는 데이터와 UNASSIGNED 데이터는 현재 프로필에 등록합니다.
- 표시 방식·스크롤 배율·읽기 위치·진행률·썸네일 등 현재 항목 필드를 보존합니다. 원본에 없는 필드는 현재 기본값 또는 빈 값(NULL)을 사용하며 기존 빈 문자열과 실제 파일명·경로는 유지합니다.
- 미리보기에 대상 프로필을 표시하고 완료 안내에 생성한 프로필 건수를 표시합니다. 미디어 항목이 없는 프로필과 설정도 가져올 수 있습니다.
- 가져오기 전체를 하나의 transaction으로 처리하여 중간 오류가 발생하면 변경을 되돌립니다.

## 기존 데이터 사용

- 설정 → 프로필 관리 → `과거 데이터 불러오기`에서 원본 `.db` 파일을 다시 선택합니다.
- 이전 가져오기로 GUEST에 잘못 등록된 항목은 자동 삭제하거나 이동하지 않습니다. 원본 DB를 다시 가져오면 원래 프로필 소속의 데이터를 별도로 복원합니다.
- 원본 DB는 읽기 전용으로 열며 변경하지 않습니다.

## 검증

- 프로필 복원·데이터 필드 보존·기본값·빈 문자열·중복 유지·반복 가져오기·오류 rollback 회귀 테스트를 추가했습니다.
- 단위·통합 테스트 139개, 가져오기·프로필 전환을 포함한 Electron E2E 전체 40개, main/preload·renderer 타입 검사와 production build가 통과했습니다.
