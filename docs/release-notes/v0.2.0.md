## 릴리즈 개요

- 버전: v0.2.0
- 비교 기준: v0.1.0
- 복수 플레이리스트, PDF·ZIP 스크롤 보기와 ZIP 성능 개선을 추가하고, 라이브러리·뷰어의 상태 유지와 오류 대응을 보강했습니다.
- 프로필·가져오기·파일 재연결·키보드·포커스 회귀 테스트와 화면 구조·문서 안정화 작업을 함께 반영했습니다.

## 주요 기능

- 프로필별 복수 플레이리스트를 생성·이름 변경·삭제·선택하며 목록별 항목과 순서를 관리합니다. 선택 목록 복원, 여러 목록 등록과 마지막 목록 삭제 차단을 지원합니다.
- 뷰어는 진입 시 플레이리스트를 유지하며 PDF·ZIP·비디오 간 이전/다음과 자동 이어보기를 제공합니다. 뷰어 목록은 열람 전용이며 편집은 라이브러리에서 수행합니다.
- PDF·ZIP의 스크롤 보기와 항목별 표시 방식·배율·읽기 위치 저장을 추가했습니다. 한 페이지·두 페이지 방향 전환과 스크롤 전용 50~300% 배율을 제공합니다.
- 콘텐츠 분류와 실제 파일 타입을 구분합니다. 콘텐츠 분류는 사용자가 지정하고 뷰어와 진행률 단위는 파일 타입으로 결정합니다.
- 프로필 단위 태그명 변경·병합을 추가했습니다. 중복 이름은 연결 항목을 보존하며 병합하고 선택한 검색 조건도 갱신합니다.
- 언어 미지정과 언어 없음을 구분하고 태그 검색 후보·선택 목록과 메타데이터 보완 흐름을 개선했습니다.

## UI/UX와 오류 수정

- 뷰어에서 돌아올 때 라이브러리 검색·페이지·선택·스크롤을 유지하며 저장 응답을 반영합니다. 썸네일 결과와 진행 중 요청도 세션에서 공유합니다.
- 설정을 기본 설정·데이터 관리·프로필 관리 탭으로 정리하고 상세보기·공용 툴팁·입력 안내를 개선했습니다.
- 창 위치·크기·모니터·최대화 상태를 복원합니다. 뷰어 툴바·커서 숨김, 동영상 탐색·볼륨 바와 스크롤·배율 단축키를 개선했습니다.
- 저장하는 사용자 텍스트의 앞뒤 공백을 정리하며 선택 입력의 빈 값과 필수 이름 검사를 구분합니다.
- HDT 미리보기의 다른 프로필 적용을 차단하고 취소·화면 이탈 후 늦은 응답과 추가 요청 처리를 보완했습니다.
- Modal 포커스 복귀와 최초 라이브러리 스크롤 기록 누락을 수정했습니다. 마우스 보조 버튼의 방문 기록 이동과 뷰어 플레이리스트 편집 진입을 차단합니다.
- 신규 파일·HDT·과거 DB 가져오기 후 목록과 페이지 수·재생 시간 보완 결과를 갱신합니다.

## 구조와 성능

- ZIP 읽기·JSZip 열기를 세션마다 한 번 수행하고 바이너리 IPC·Blob URL·이미지 decode와 주변 미리 읽기를 사용합니다. 범위 밖 이미지와 오래된 응답은 해제합니다.
- ZIP 이미지 보관의 128MiB는 추정 예산이며 앱 전체 메모리 상한은 아닙니다. 측정 조건·결과는 [ZIP 성능](https://github.com/jeonhs9519/media-library-desktop/blob/v0.2.0/docs/zip-performance.md)을 참조합니다.
- 시작·프로필 선택 화면, 라이브러리 조회·갱신·이동/복사, 상세보기 처리·팝업을 전용 hook·컴포넌트로 분리했습니다. 프로필·번역 타입과 Toast를 공유합니다.
- 현재 상태·검증·과거 이력과 후속 계획을 정리하고 개발 환경·DB 오류 대응·CI 검사 안내를 실제 구현에 맞췄습니다.

## 기존 데이터 사용

- 기존 DB는 앱 시작 시 필요한 스키마를 갱신합니다. 업데이트 전 앱을 종료하고 `media-library.db`와 `.data/`, 남아 있는 `-wal`·`-shm` 파일을 백업합니다.
- 새 폴더에서 실행할 때는 기존 DB와 `.data/`를 함께 옮깁니다. 과거 userData 위치의 DB는 설정 → 프로필 관리 → 과거 데이터 불러오기에서 직접 선택합니다.
- 플레이리스트 삭제·초기화와 라이브러리 항목 삭제는 원본 파일을 삭제하지 않습니다.

## 릴리즈 전 검증

- 단위·통합 테스트: 21개 파일, 132개 통과
- Electron E2E: 전체 38개 통과
- main/preload·renderer 타입 검사와 production build 통과
- E2E는 임시 DB·합성 파일을 사용하며 필요한 시나리오에서 OS 파일 선택·외부 URL 응답을 대체합니다. Windows ZIP 패키징·업로드는 태그 기반 CI에서 별도로 수행합니다.
