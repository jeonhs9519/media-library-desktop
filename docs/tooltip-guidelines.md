# 툴팁 기준

Last updated: 2026-10-04

새 툴팁은 공용 `src/renderer/src/components/Tooltip`을 사용합니다. 기존 브라우저 기본 `title` 안내는 개별 화면을 수정할 때 전환 여부를 검토합니다.

## 표시와 위치

- 트리거의 마우스 호버 또는 키보드 포커스 시 표시합니다. 툴팁 위로 포인터를 옮겨도 유지하고, 호버와 포커스가 모두 해제되면 숨깁니다. Escape는 포커스를 유지한 채 툴팁만 닫습니다.
- 기본 위치는 트리거 바로 아래이며, 트리거 왼쪽 끝과 툴팁 왼쪽 끝을 맞춥니다.
- 기본 폭은 테두리와 내부 패딩을 포함한 `240px`입니다. `width`로 변경할 수 있습니다.
- 오른쪽 경계를 초과하면 `컨테이너 오른쪽 경계 - 툴팁 폭` 위치로 옮깁니다. 왼쪽 경계도 보호합니다.
- 컨테이너가 툴팁보다 좁으면 지정한 폭을 유지하며 오른쪽 경계를 우선합니다. 이 경우 왼쪽으로 넘칠 수 있습니다.
- 툴팁은 별도 줄이나 공간을 만들지 않고 화면 위에 겹쳐 표시합니다. 스크롤·창 크기·컨테이너나 툴팁 크기가 바뀌면 위치를 다시 계산합니다.
- 툴팁 생성 직후 첫 화면 표시 전에 위치를 계산합니다. 숨겨도 계산된 위치를 유지하며, 숨겨진 상태에서도 크기 변경과 스크롤에 따라 다시 계산합니다. 표시 여부를 위치 계산의 조건으로 사용하거나 닫을 때 `left: 0`으로 초기화하지 않습니다.
- 트리거는 포커스 가능한 요소와 접근 가능한 이름을 제공해야 합니다. 툴팁은 `role="tooltip"`과 고유 id를 가지며, 트리거에 `aria-describedby`로 연결됩니다.

## 컨테이너와 경계

영역에 `tooltip-container` 클래스를 지정합니다. 툴팁은 트리거의 조상 중 가장 가까운 영역을 사용하므로 중첩 컨테이너도 지원합니다. 영역이 없으면 화면 좌우 경계를 사용합니다. `containerSelector`로 다른 클래스나 속성 선택자를 지정할 수 있습니다.

컨테이너의 `data-tooltip-boundary`는 경계를 선택하는 옵션이며, 요소 자체의 CSS `box-sizing`을 변경하지 않습니다.

| 값 | 경계 기준 |
| --- | --- |
| `content-box` (기본값) | 테두리와 패딩을 제외한 콘텐츠 영역. 패딩만큼 안쪽 여백을 지킵니다. |
| `padding-box` | 패딩을 포함하고 테두리는 제외한 영역. |
| `border-box` | 테두리를 포함한 바깥쪽 영역. |

`content-box`와 `padding-box`는 세로 스크롤바 공간도 제외합니다. 컨테이너는 시각적 범위와 위치 계산 기준을 지정하며, 상위 요소의 `overflow`에 의한 잘림을 해제하지는 않습니다.

```tsx
<section className="tooltip-container" data-tooltip-boundary="content-box">
  <Tooltip content="안내 문구">
    <button type="button" aria-label="항목 안내">...</button>
  </Tooltip>
</section>
```

## 상세보기 언어 안내 적용

- 언어가 이미 지정된 항목의 수정 모드에서만 원형 물음표를 표시합니다.
- `메타데이터` 항목 전체를 컨테이너로 지정하고 `content-box`를 적용합니다.
- 메타데이터의 `16px` 패딩을 지키므로, 오른쪽 보정 시 툴팁 오른쪽 끝은 언어 선택란의 오른쪽 끝과 일치합니다.
