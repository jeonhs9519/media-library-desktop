## 테스트 보강

- 핵심 사용자 흐름 테스트 보강 시 상세 삭제 확인 Modal, 뷰어 썸네일 toast, 플레이리스트 Delete 삭제 후 active 상태 유지 동작을 함께 검증

## 접근성 및 UX

- 프로필 선택 화면, 삭제 Modal, 상세 정보 모달 프로필 이동 항목의 키보드 조작을 자동 또는 수동 테스트 체크리스트로 보강
- 검색 조건 팝업의 태그 조건 영역에서 선택된 태그 목록을 한 줄로 표시하고, 초과 시 가로 스크롤을 적용
- 검색 조건 팝업의 태그 조건 영역에 태그 검색 폼과 선택 버튼을 추가해 검색한 태그를 검색조건에 포함할 수 있게 개선
- 검색 조건 팝업의 등록된 태그 목록은 기존 목록과 더보기 버튼 동작을 유지하며, 선택된 태그 목록, 태그 검색 폼/선택 버튼, 등록된 태그 목록 순서로 배치
- 파일 메타데이터와 검색 조건의 언어 구분에 `없음` 선택지를 추가

## 앱 실행 상태 유지

- 마지막 실행 창의 크기, 좌표, 표시 모니터 정보를 저장하고 다음 실행 시 같은 창 경험을 복원

## 태그 관리

- 지정한 태그를 태그명과 내부 id 기준으로 조회하고, 태그명을 변경해 해당 태그가 연결된 항목 전체에 일괄 반영
- 변경하려는 태그명이 같은 프로필에 이미 존재하면, 태그 id가 더 작은 먼저 생성된 태그로 연결 항목을 병합

## 동영상 뷰어

- seek bar에 마우스를 올렸을 때 hover 위치와 현재 재생 상태를 함께 표시
- seek bar 표시 elevation은 배경, 마우스 hover 위치, 현재 재생 상태 순서로 겹치게 조정

## 뷰어 공통

- 뷰어의 툴바 영역 자동 숨김 시간을 2.4초로 조정
- 창 안에 커서가 있더라도 2.4초 동안 움직임이 없으면 툴바 영역과 커서를 함께 숨김
- 커서가 다시 움직이면 툴바 영역과 커서를 다시 표시

## ZIP 뷰어 성능

- 큰 ZIP 파일을 뷰어에서 열람할 때 다음 페이지를 불러오는 과정에서 버벅임이 발생하는 문제 확인
- ZIP 내부 이미지 로딩, 압축 해제, 다음/이전 페이지 preloading 또는 caching 흐름을 점검하고 필요한 조치를 적용

## 도서/만화 뷰어 표시 방식

- 도서/만화 뷰어의 한 페이지 보기에 스크롤 보기 옵션을 추가
- 스크롤 보기는 두 페이지 보기와 같이 단축키 `1`로 토글
- 뷰어 표시 방식의 기본값은 한 페이지 보기로 유지
- 도서/만화 데이터에 페이지 방향/표시 방식 값을 저장
- 페이지 방향/표시 방식은 한 페이지 보기, 스크롤 보기, 왼쪽 -> 오른쪽, 오른쪽 -> 왼쪽 중 하나로 지정
- 저장된 페이지 방향/표시 방식 값이 없는 데이터는 한 페이지 보기를 기본값으로 사용
