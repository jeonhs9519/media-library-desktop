## 도서/만화 뷰어 표시 방식

- 도서/만화 뷰어의 한 페이지 보기에 스크롤 보기 옵션을 추가
- 스크롤 보기는 두 페이지 보기와 같이 단축키 `1`로 토글
- 뷰어 표시 방식의 기본값은 한 페이지 보기로 유지
- 도서/만화 데이터에 페이지 방향/표시 방식 값을 저장
- 페이지 방향/표시 방식은 한 페이지 보기, 스크롤 보기, 왼쪽 -> 오른쪽, 오른쪽 -> 왼쪽 중 하나로 지정
- 저장된 페이지 방향/표시 방식 값이 없는 데이터는 한 페이지 보기를 기본값으로 사용
