# Current Status

Last updated: 2026-10-05

이 문서는 현재 소스의 구현 상태를 기록합니다. `package.json` 버전은 `0.1.0`이며, 이후 구현한 기능과 안정화 작업도 포함합니다. 배포 버전별 기능은 [릴리즈 노트](release-notes/), 작업 이력은 [Changelog](changelog.md)에서 확인합니다.

## 완료 범위

- 기존 Electron 기능 개선, 테스트 보강, 구조 안정화와 문서 안정화를 완료했습니다.
- 합의한 Electron 작업 범위에서 다음 개발 작업으로 남겨 둔 항목은 없습니다.
- Tauri + Rust + Svelte 재구축은 별도 요청으로 착수할 후속 범위입니다. 준비 문서와 신규 프로젝트는 아직 작성·생성하지 않았습니다.
- 플레이리스트 복제·내보내기는 구현 범위와 후속 후보에서 제외합니다.

## 라이브러리와 항목 관리

- PDF, ZIP(CBZ 포함), 비디오와 기타 파일을 등록하며 중복은 현재 프로필의 경로·파일명·확장자로 판정합니다.
- 콘텐츠 분류(`contentType`)와 파일 타입(`containerType`)을 구분합니다. 일반 등록·HDT 가져오기는 PDF/ZIP을 도서, 비디오를 동영상으로 기본 분류하며 뷰어·진행률 단위·플레이리스트 등록 가능 여부는 파일 타입으로 결정합니다.
- 제목·작성자·메모·원본 URL·언어·태그·리뷰·썸네일·진행률을 관리합니다. 언어 `unspecified`와 `none`은 별도 값이며, 지정한 언어는 UI와 IPC에서 미지정으로 되돌리지 못하게 제한합니다.
- 사용자 텍스트는 저장 전 앞뒤 공백을 제거하고 내부 공백·줄바꿈을 유지합니다. 선택 입력의 공백만 있는 값은 빈 문자열로 저장하고 필수 이름은 정리 후 검사합니다. 실제 파일명·경로는 이 입력 정리 대상에서 제외합니다.
- 상세보기에서 편집·삭제·파일 재연결과 프로필 이동·복사를 수행합니다. 삭제는 DB 항목과 연결 데이터를 제거하며 원본 파일은 유지합니다. 외부 프로그램·원본 URL·파일 위치 열기를 제공합니다.
- 검색어는 제목·파일명·작성자·메모·원본 URL을 대상으로 합니다. 콘텐츠 분류·언어·진행 상태·파일 존재 여부·태그 AND/미지정 조건과 정렬·페이지네이션을 함께 사용합니다.
- 목록은 단일 Tab 진입과 방향키·Home/End 탐색을 지원합니다. 빈 공간 클릭은 선택·스크롤을 바꾸지 않습니다. 검색은 라이브러리의 `Ctrl+F`/`Cmd+F`로 열며 뷰어에서 비활성화합니다.
- 태그 검색 후보는 실제 사용 중인 태그입니다. 기본 최대 20건, 태그명 변경·병합은 최대 50건이며 변경 전은 건수 오름차순, 변경 후는 내림차순입니다.
- 태그명 중복은 작은 id를 유지하는 transaction으로 병합하고 선택 검색 조건도 치환합니다. 연결 항목이 없는 태그는 정리합니다.

## 프로필

- `SYSTEM = 1`, `UNASSIGNED = 2`, `GUEST = 3`이며 사용자 프로필은 id 4부터 생성합니다. SYSTEM·UNASSIGNED는 선택 화면에 표시하지 않습니다.
- 프로필 선택 화면에서 생성·선택·사용자 프로필 삭제를 처리합니다. 이름은 최대 16자이며 GUEST 이름 변경은 차단합니다. 미귀속 기존 데이터는 처음 선택한 프로필로 이관합니다.
- 항목·태그·플레이리스트·사용자 설정을 프로필별로 분리합니다. UI 언어·동영상 볼륨·파일 수정일 정책·최근 프로필·자동 진입 설정은 SYSTEM에 저장합니다.
- 최근 사용 프로필을 최대 2개 기억하고 자동 진입을 지원합니다. 마지막 프로필이 삭제되면 직전 유효 프로필 또는 GUEST로 복귀합니다.
- 삭제 확인에서 데이터 함께 삭제 또는 다른 프로필로 이관을 선택합니다. 중복 시 대상 데이터 유지/원본 데이터로 덮어쓰기를 선택하고, 삭제 프로필의 플레이리스트는 제거합니다.
- 항목 이동·복사는 진행률·리뷰·태그·표시 방식 등을 보존합니다. 대상의 동일 파일은 중복으로 차단하며 이동한 항목은 기존 플레이리스트에서 제거하고 대상 플레이리스트에는 자동 추가하지 않습니다.

## 복수 플레이리스트

- 프로필마다 생성·이름 변경·삭제·선택·초기화와 항목 추가·제거·재정렬을 지원합니다. 선택 목록은 `playlist.activeId`에 저장합니다.
- 이름은 앞뒤 공백 제거 후 1~100자이고 같은 프로필 내 중복 이름을 차단합니다. 마지막 목록은 삭제할 수 없으며 목록이 전혀 없을 때만 Default를 생성합니다.
- 좌/우 표시와 접힘 상태를 저장합니다. 선택 필드에는 이름·건수를 표시하고 관리 버튼은 공용 아이콘·다국어 접근성 이름을 사용합니다.
- 버튼·drop은 선택한 목록에 추가합니다. 카드 메뉴에서는 모든 목록의 등록 체크와 현재 목록을 표시하고 다른 목록에도 추가할 수 있습니다. 한 항목은 여러 목록에 등록할 수 있습니다.
- 일반 중복 추가는 순서를 유지하며 위치 지정 drop은 해당 위치로 이동합니다. 항목 추가는 접힘 상태를 유지하고 이미 펼친 패널에서만 포커스를 옮깁니다.
- 목록은 단일 Tab 진입과 위/아래 탐색을 지원합니다. 라이브러리에서 Delete로 제거한 뒤 남은 인접 항목으로 포커스를 이어가며 빈 목록은 컨테이너에 둡니다.
- 뷰어 목록은 열람 전용입니다. 편집 버튼·메뉴·Delete·순서 변경 단축키·drag/drop을 차단하고 처리한 키 입력은 뷰어로 전파하지 않습니다.
- 뷰어 진입 시 목록 id를 고정하며 PDF·ZIP·비디오 간 이전/다음·자동 이어보기에도 유지합니다. 현재 항목이 진입 목록에 없으면 목록 이동과 자동 이어보기를 실행하지 않습니다.
- 뷰어에서 `L`은 목록 표시를 전환하고 `PgUp`/`PgDown`은 이전/다음 목록 항목을 엽니다.
- 도서·만화는 마지막 페이지에서 다음 이동을 요청할 때, 동영상은 반복 재생을 끈 상태에서 재생 완료할 때 다음 항목을 엽니다.
- 삭제·초기화는 등록 관계만 제거하고 라이브러리 항목·실제 파일을 유지합니다. 과거 DB 가져오기는 복수 목록과 선택 목록 id 매핑을 지원합니다.

## 뷰어와 자원 관리

- PDF·ZIP은 한 페이지, 스크롤, 두 페이지 좌→우/우→좌를 제공합니다. 항목별 `bookViewMode`에 저장하며 저장값이 없으면 한 페이지로 엽니다.
- `1`은 한 페이지↔스크롤, `2`는 두 페이지 방향 전환입니다. 스크롤에서 위 방향키·`zxcvbnm,./`는 위로, 아래 방향키·Space는 아래로 반 화면 이동하며 좌/우 방향키는 페이지를 이동합니다.
- 스크롤 기본 폭은 컨테이너와 1000px 중 작은 폭입니다. 전용 툴바·컨텍스트 메뉴·`+`/`-`로 50~300%를 25%씩 조절하며 `0`과 배율 버튼은 100%로 초기화합니다.
- `bookScrollZoom`과 페이지 내 위치 비율 `bookScrollOffset`을 항목에 저장합니다. 180ms debounce와 종료·전환 시 저장을 적용하고 배율·창 크기 변경 뒤 읽던 위치를 복원합니다.
- 스크롤은 실제 이미지 높이로 간격 없이 배치하며 화면 주변만 렌더링합니다. PDF는 범위 밖 작업을 취소하고 큰 canvas 버퍼를 제한합니다.
- ZIP은 sender별 세션에서 파일 읽기·JSZip 열기를 한 번 수행합니다. 바이너리 IPC·Blob URL·이미지 decode와 주변 미리 읽기를 사용하고 오래된 응답·범위 밖 URL을 해제합니다.
- ZIP의 128MiB는 이미지 보관 추정 예산입니다. 현재 화면 표시를 우선하며 앱 전체 메모리 상한은 아닙니다. 자세한 조건과 과거 측정값은 [ZIP 성능](zip-performance.md)을 참조합니다.
- 모든 뷰어의 툴바·커서는 2.4초 idle 후 숨깁니다. PDF·ZIP은 Tab·컨텍스트 메뉴 접근 키로, 동영상은 모든 키 입력으로 다시 표시합니다. 열린 컨텍스트 메뉴는 숨김을 보류합니다.
- Esc·Backspace로 라이브러리에 복귀하며 앱 전체에서 마우스 뒤로가기·앞으로가기의 기본 방문 기록 이동을 차단합니다.

## 가져오기와 설정

- 설정은 기본 설정, 데이터 관리, 프로필 관리의 세 탭입니다. 닫았다 다시 열면 기본 설정부터 표시합니다.
- 기본 설정은 표시·앱 배율·파일 수정일 정책, 데이터 관리는 태그명 변경·병합·폴더 경로 일괄 변경·HDT 가져오기, 프로필 관리는 이름 변경·과거 DB 가져오기를 제공합니다.
- HDT와 과거 DB는 미리보기 후 적용합니다. HDT 미리보기는 준비한 프로필에서만 적용하며 취소·화면 이탈 후 늦은 응답을 반영하지 않습니다.
- 파일 추가는 화면 이탈 후 남은 요청과 목록 갱신을 중단합니다. 개별 재연결·폴더 경로 일괄 변경은 중복 충돌을 검사하고 충돌 시 데이터를 보존합니다.
- 신규 파일·HDT·과거 DB 가져오기 후 목록과 페이지 수·재생 시간 보완을 갱신합니다. 복수 추가는 묶음당 갱신하고 진행 중 Queue에 추가된 항목은 완료 후 재수집합니다.
- 과거 userData DB는 자동 복사하지 않으며 설정에서 직접 선택합니다. 항목·태그·플레이리스트·사용자 설정은 현재 프로필에, SYSTEM 설정은 SYSTEM에 가져옵니다.
- 한국어·영어·일본어·중국어 UI를 제공합니다. 확인·오류는 공용 Modal, 완료 알림은 Toast를 사용합니다.

## 시작·복귀와 구조

- 창을 먼저 표시하고 startup 화면에서 DB·스키마·IPC 준비를 안내합니다. 최초 라이브러리 목록 표시를 준비 완료 기준으로 삼고 썸네일·뷰어 route preload는 이후 진행합니다.
- 창 좌표·크기·모니터·최대화 상태는 포터블 userData의 `window-state.json`에 저장합니다. 전체화면·최소화는 복원하지 않으며 모니터 변경 시 작업 영역에 맞춥니다.
- 뷰어 동안 라이브러리를 숨겨 보관하고 검색·페이지·선택·스크롤을 유지합니다. 저장 응답을 목록에 반영하며 읽기 상태 필터나 수정일 정렬에 영향을 주는 경우 복귀 시 재조회합니다.
- 썸네일 결과와 진행 중 요청은 렌더러 세션에서 공유합니다. 저장·삭제·이동은 항목별, 프로필 전환·삭제는 전체 캐시를 무효화합니다.
- App은 시작·프로필 gate와 라우트 조립을 담당합니다. 라이브러리 조회·갱신·이동/복사, 상세보기 조회·편집·태그·리뷰·파일 처리·팝업은 전용 hook·컴포넌트로 분리했습니다.
- 프로필·번역 타입과 Modal·Toast를 공유합니다. 자세한 모듈 경계·파일 맵·IPC는 [Architecture](architecture.md)에 기록합니다.

## 데이터 위치와 후속 범위

- 개발 앱은 프로젝트 루트, 배포 앱은 실행 파일 폴더의 `media-library.db`와 `.data/`를 사용합니다. 백업·이동은 앱을 종료한 뒤 함께 수행합니다.
- 현재 소스는 Electron 기준 구현체입니다. 재구축 준비·착수 순서는 [Next Task](next-task.md)와 [Backlog](backlog.md)에서 관리합니다.
