# Roadmap

Last reviewed: 2026-10-05

## 현재 기준

- Electron 기능 개선, 테스트 보강, 구조 안정화와 문서 안정화를 완료했습니다.
- 현재 구현과 최신 검증은 [Current Status](current-status.md)에 기록합니다.
- 합의한 Electron 범위의 추가 개발 작업은 없습니다. 새 요구가 생기면 범위를 정한 뒤 계획에 반영합니다.

## 다음 별도 범위

- Tauri 재구축 요청 시 테스트 시나리오 → 소스 분석 문서 → 재구축 계획서 순으로 준비합니다.
- 준비 문서 이후 Tauri + Rust + Svelte 신규 프로젝트를 생성하고 기능 단위로 재구축합니다.
- 기존 Electron 앱은 비교 기준으로 유지하며 단계마다 기능·데이터 처리·화면 동작을 대조합니다.
- 착수 순서는 [Next Task](next-task.md), 미착수 후보는 [Backlog](backlog.md)에서 관리합니다.

## 유지 기준

- 기능 변경 시 해당 회귀 테스트와 문서를 함께 갱신합니다.
- 분리한 컴포넌트·hook 경계를 유지하고 공용 프로필·i18n 타입, Toast·Modal을 재사용합니다.
- 새로운 기능이나 실제 병목이 확인되면 필요한 구조·성능 변경만 범위에 추가합니다.
- 완료된 작업은 예정 목록에서 제거하고 변경 이력에 남깁니다.
